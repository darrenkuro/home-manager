# Obsidian Plugin Build Setup Reference

## manifest.json

```json
{
  "id": "plugin-id",
  "name": "Plugin Name",
  "version": "0.1.0",
  "minAppVersion": "1.5.7",
  "description": "Brief description of the plugin.",
  "author": "Darren Kuro",
  "isDesktopOnly": false
}
```

- `id` must be kebab-case, match the GitHub repo name
- `version` is synced by `version-bump.mjs`
- `minAppVersion` should match the minimum Obsidian version your API usage requires

## versions.json

```json
{
  "0.1.0": "1.5.7"
}
```

Maps plugin versions to minimum Obsidian versions. Updated automatically by `version-bump.mjs`.

The `"version"` script is a lifecycle hook — npm/pnpm runs it automatically when `pnpm version patch/minor/major` is executed.

## .npmrc

```
tag-version-prefix=""
```

This makes `pnpm version` create tags like `1.0.1` instead of `v1.0.1`. Obsidian/BRAT expects bare semver tags.

## esbuild.config.mjs

```js
import esbuild from "esbuild";
import process from "process";
import builtins from "builtin-modules";

const banner = `/*
THIS IS A GENERATED/BUNDLED FILE BY ESBUILD
if you want to view the source, please visit the github repository of this plugin
*/
`;

const prod = process.argv[2] === "production";

const context = await esbuild.context({
  banner: { js: banner },
  entryPoints: ["src/main.ts"],
  bundle: true,
  external: [
    "obsidian",
    "electron",
    "@codemirror/autocomplete",
    "@codemirror/collab",
    "@codemirror/commands",
    "@codemirror/language",
    "@codemirror/lint",
    "@codemirror/search",
    "@codemirror/state",
    "@codemirror/view",
    "@lezer/common",
    "@lezer/highlight",
    "@lezer/lr",
    ...builtins,
  ],
  format: "cjs",
  target: "es2018",
  logLevel: "info",
  sourcemap: prod ? false : "inline",
  treeShaking: true,
  outfile: "main.js",
  minify: prod,
});

if (prod) {
  await context.rebuild();
  process.exit(0);
} else {
  await context.watch();
}
```

## version-bump.mjs

```js
import { readFileSync, writeFileSync } from "fs";

const targetVersion = process.env.npm_package_version;

// Update manifest.json
const manifest = JSON.parse(readFileSync("manifest.json", "utf8"));
const { minAppVersion } = manifest;
manifest.version = targetVersion;
writeFileSync("manifest.json", JSON.stringify(manifest, null, "\t"));

// Update versions.json
const versions = JSON.parse(readFileSync("versions.json", "utf8"));
versions[targetVersion] = minAppVersion;
writeFileSync("versions.json", JSON.stringify(versions, null, "\t"));
```

## src/main.ts (Scaffold Template)

```ts
import { Plugin } from "obsidian";
import { DEFAULT_SETTINGS, MyPluginSettings, MySettingTab } from "./settings";

export default class MyPlugin extends Plugin {
  settings: MyPluginSettings;

  async onload() {
    await this.loadSettings();

    this.addSettingTab(new MySettingTab(this.app, this));

    // Register commands, events, views here
  }

  async onunload() {
    // Custom cleanup only — registered events/intervals are auto-cleaned
  }

  async loadSettings() {
    this.settings = Object.assign({}, DEFAULT_SETTINGS, await this.loadData());
  }

  async saveSettings() {
    await this.saveData(this.settings);
  }
}
```

## .github/workflows/release.yml

```yaml
name: Release

on:
  push:
    tags:
      - "*"

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
      - uses: actions/checkout@v4

      - uses: pnpm/action-setup@v4
        with:
          version: 9

      - uses: actions/setup-node@v4
        with:
          node-version: "22"
          cache: "pnpm"

      - run: pnpm install --frozen-lockfile

      - run: pnpm run build

      - uses: softprops/action-gh-release@v2
        with:
          draft: true
          files: |
            main.js
            manifest.json
            styles.css
```

The release is created as a **draft** — review and publish manually or set `draft: false` for auto-publish.

BRAT requires `main.js`, `manifest.json`, and `styles.css` as release assets.

## styles.css

Create an empty `styles.css` file in the project root. This file is required by BRAT as a release asset even if no custom styles are needed.

## Testing via BRAT

Install the plugin in a vault using BRAT (Beta Reviewers Auto-update Tester):

1. Push and tag a release (see flow below)
2. In Obsidian: BRAT settings → "Add Beta Plugin" → enter `<github-username>/<repo-name>`
3. BRAT auto-updates when new releases are published
4. Reload Obsidian (Cmd+R) to pick up changes

## Version Bump & Release Flow

```bash
# 1. Commit all changes
git add -A && git commit -m "feat: add new feature"

# 2. Bump version (triggers version-bump.mjs via npm lifecycle)
pnpm version patch   # or minor, major

# 3. Push code and tags
git push && git push --tags

# 4. Tag push triggers release.yml → draft GitHub release
# 5. BRAT auto-detects the new release
```
